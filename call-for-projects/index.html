Project Evaluation

Relevance
—A project that addresses a new or emerging cybersecurity threat.
—A project that applies cybersecurity principles to a new or innovative application.
—A project that demonstrates the use of cybersecurity technologies to solve a real-world problem.
Innovation
—A project that proposes a new approach to cybersecurity that has not been previously implemented.
—A project that improves upon an existing cybersecurity solution.
—A project that demonstrates the use of new or emerging technologies to improve cybersecurity.
Technical Merit
—A project that is well-designed and implemented.
—A project that is free of errors or vulnerabilities.
Communication
—A project that is well-documented and easy to understand.
—A project that is presented in a clear and concise manner.
—A project that is original and interesting.
